Scope

01 / 05

Everything an agent needs.

Built agent-first: extraction over pixels, selectors over coordinates, failures you can catch instead of hangs. The automation surface is deliberately small.

CommandCovers
readStructured page reads. Prose via read_page(), or read_structure(): every element with its rect and selector; fields carry label, constraints, state and validity.
actSelector interaction. click_element() and set_value() — real pointer events, React/Vue-safe writes.
waitSPA-aware timing. Wait for selectors and readiness — no sleeps, no flaky scripts.
observeConsole capture. Page messages and network errors arrive as events.
filesDownloads. Fetched straight to disk, without page cookies.
surviveFast failure, not hangs. A dead engine surfaces instantly; ephemeral profiles give every run a clean slate.
blockAdblock built in. EasyList-based, refreshed weekly.
gpuRendering. CPU by default — starts anywhere; --gpu opts into hardware. Screenshots on demand, per tab.
secureToken-gated attach. Unauthenticated sockets get nothing — not even events.
interceptFail-closed interception. Requests held for an allow / deny / respond decision; unanswered means denied after 5 s.
authChallenges surfaced, not swallowed. Auth and file-picker events; missing credentials fail closed.
evidenceNet evidence. Every fetch/XHR recorded in a ring buffer, in every frame.
framesFrame tree. List frames and walk same-origin ones; cross-origin frames report their url only.
fillForm filling. A whole form in one round trip, with type-aware writes.
submitSubmit and read the outcome. Runs the page's validation, then reports url, alerts and invalid fields.
pointShared references. Stable refs and numbered screenshot boxes: the agent says "click 7" and the human knows which one that is.
handoffHumans take over when it matters. detect_handoff() spots CAPTCHAs, codes and payment fields; pause() blocks mutations while they work. Fail-closed: unanswered means blocked, not guessed.
trustFail-closed by design. Persistent profiles, evidence shots, an append-only action log, a credential store and a confirm gate on payment submits.

Protocol

02 / 05

The entire protocol, in full.

Newline-delimited JSON over loopback. One client, no hidden state — the opposite of CDP's 1000+ endpoints. Events: url, title, history, cursor, favicon, pwcapture, evalresult, pong, console, download, request, auth, filepicker.

SDK

03 / 05

Three ways in.

Same engine underneath; pick the integration you already have.

SurfaceCovers
mcpModel Context Protocol server with 36 tools, stdlib only. Any MCP-capable agent — Claude, Kai, your own — drives Browserr with zero integration code.
pythondriver.py wraps the raw protocol: navigation, extraction, form filling, screenshots. No dependencies.
rawAnything that can write JSON lines to a socket. Bindings in any language are an afternoon.
