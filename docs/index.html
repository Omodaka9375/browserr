Scope

01 / 05

Everything an agent needs.

Built agent-first: extraction over pixels, stable refs over coordinates, failures you can catch instead of hangs. Three commitments shape the whole engine: it blocks when unsure, it hands the page to a human when a human is needed, and it leaves evidence for everything it did.

CapabilityCovers
Read and act
readStructured reads. Prose via read_page(), or read_structure(): every element with its rect, selector and a stable ref; fields carry label, constraints and validity.
actReal interaction. Selector or ref clicks with a real pointer, and React/Vue-safe value writes.
waitSPA-aware timing. Wait for selectors and readiness — no sleeps, no flaky scripts.
fillForms in one round trip. A whole form per call, with type-aware writes and the page's own validation on submit.
observeConsole capture. Page messages plus network and TLS failures arrive as events.
Network and control
interceptFail-closed interception. Requests held for allow / deny / respond; unanswered means denied after 5 s.
authChallenges surfaced. Auth and file-picker events; missing credentials fail closed.
proxyUpstream proxy routing. CONNECT tunnels with basic auth and per-engine rotation; document_status reveals the real HTTP status behind a fake-404 block.
evidenceNet evidence. Every fetch/XHR recorded in a ring buffer, in every frame.
framesFrame tree. Same-origin frames are walked; cross-origin frames report their url only.
filesDownloads. Straight to disk, cookieless by default; opt in to the tab's session for logged-in portals.
Human handoff and trust
pointShared references. Stable refs and numbered screenshot boxes: the agent says "click e7" and the human sees which one that is.
handoffHumans take over. headed:true opens a real native window; mouse and keyboard keep working while agent mutations are paused.
trustFail-closed by design. Evidence shots, an append-only action log, a credential store and a confirm gate on payment submits.
secureToken-gated attach. Unauthenticated sockets get nothing — not even events.
Runtime
gpuRendering. CPU by default — starts anywhere; --gpu opts into hardware. Screenshots on demand, per tab.
compatSPA-ready. React 18 and Vue 3 render and react; WebGL, IndexedDB, Web Animations and clipboard; shims where Servo omits an API.
blockAdblock built in. EasyList-based, refreshed weekly.
termBrowse in your terminal. Real pages inside a pane at native resolution (Sixel / Kitty, engine-side dirty rectangles), tmux included.
surviveFast failure, not hangs. A dead engine surfaces instantly; ephemeral profiles give every run a clean slate.

Three ways in.

Same engine underneath; pick the integration you already have.

Install

05 / 05

Get Browserr in seconds.

One command for MCP clients; one package per platform for everything else.

Any MCP client

No download, no paths. The engine is fetched and sha256-verified on first run; later starts are instant and never depend on a live GitHub API call.

{
  "mcpServers": {
    "browserr": { "command": "uvx", "args": ["browserr-mcp"] }
  }
}

Package: browserr-mcp on PyPI. Or prefer an archive:

Windows x64

Download the zip, unpack anywhere, and point your agent at the MCP server. CPU rendering works out of the box; pass --gpu for hardware rendering.
