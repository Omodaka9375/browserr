Everything an agent needs

Built agent-first: extraction over pixels, selectors over coordinates, failures you can catch instead of hangs.

extractStructured page reads

Prose via read_page(), or read_structure(): headings, buttons, inputs, selects, links, images - each with a viewport rect and a CSS selector that feeds the element commands.

actSelector-based interaction

click_element() scrolls into view and clicks with a real pointer event. set_value() uses the native setter + input/change events, so React and Vue controlled inputs accept it.

waitSPA-aware timing

wait_for_selector() polls until an element is visible. wait_ready() gates on document.readyState. No sleeps, no flaky scripts.

observeConsole capture

Page console.log/warn/error arrives as events - and Servo routes network & TLS load errors through the same channel, so agents see why a page failed.

filesDownloads

download(url, path) fetches straight to disk with size caps and an ok/bytes/error event. Public URLs only - no page cookies involved.

surviveFast failure, not hangs

EngineDeadError surfaces a dead engine in 0.07 s instead of a timeout. ping health-checks. Ephemeral profiles give every run a clean slate.

blockAdblock built in

EasyList-based subresource blocking at the engine's request-interception hook, auto-refreshed weekly. Never blocks main-frame documents.

gpuFast rendering

Servo renders on the GPU; frames cross processes as D3D12 shared textures (no pixel copies) with byte-frame fallback. Screenshots on demand, per tab.

secureToken-gated attach

--driver-port=N accepts multiple concurrent drivers; --driver-token=T requires an auth line first. Unauthenticated sockets get nothing, not even events.

The protocol, in full

Newline-delimited JSON over loopback. One client. No hidden state. This is the entire command surface - the opposite of CDP's 1000+ endpoints.

commandwhat it does
{"cmd":"navigate"|"back"|"forward"}navigation, per tab
{"cmd":"new_tab"|"activate"|"close_tab"}tab lifecycle
{"cmd":"input"|"wheel"|"key"}per-tab pointer, wheel, keyboard input
{"cmd":"eval", "js":..., "id":N}run JS; result returns as an evalresult event (any JSON value)
{"cmd":"screenshot"}paint + answer with a BGRA frame
{"cmd":"zoom"}per-tab page zoom
{"cmd":"ping"}health check: tab count + active tab
{"cmd":"download"}fetch a URL straight to disk, capped
{"cmd":"resize"}viewport size

Events: url, title, history, cursor, favicon, pwcapture, evalresult, pong, console, download.

Three ways in

Same engine underneath; pick the integration you already have.

MCP server

Stdlib-only Model Context Protocol server with 19 tools. Any MCP-capable agent - Claude, Kai, your own - drives Browserr with zero integration code.

Python SDK

driver.py wraps the raw protocol: navigation, extraction, element commands, console capture, downloads, screenshots, and a PNG helper. No dependencies.

Raw protocol

Anything that can write JSON lines to a socket can drive the engine. The whole protocol fits on one screen; bindings in any language are an afternoon.
